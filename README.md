# 🌍 AquaSync AI
**Precision Climate Intelligence for Water-Optimized Agriculture**

## 🚀 Overview
AquaSync AI is an AI-powered platform designed for the Environmental Innovation Challenge. It merges **Climate-Smart Agriculture**, **Water Conservation**, and **Climate Tech** to prevent agricultural water waste while maximizing crop yield. 

Farmers often irrigate based on routine rather than real-time crop and climate needs, leading to avoidable water loss while climate variability increases agricultural uncertainty. AquaSync AI predicts exact crop water requirements using local weather data, soil moisture, and crop stages.

## 📁 Project Structure
- `/app` : Streamlit dashboard prototype.
- `/data` : Synthetic data generation scripts.
- `/models` : ML model training scripts.
- `/documentation` : Detailed research, architecture, and impact.
- `/presentation` : Slide-by-slide Pitch Deck content.
- `/video` : 3-minute video script and storyboard.

## 🛠️ How to Run the Prototype

1. **Install Dependencies:**
   ```bash
   pip install -r app/requirements.txt
   ```

2. **Generate Synthetic Data:**
   ```bash
   python data/generate_data.py
   ```

3. **Train the ML Models:**
   ```bash
   python models/train_model.py
   ```

4. **Launch the Dashboard:**
   ```bash
   streamlit run app/app.py
   ```

## 🌟 Unique Selling Propositions (USPs)
1. **Predictive instead of reactive:** Anticipates water needs based on 24h weather forecasts.
2. **Explainable AI recommendations:** Doesn't just say "Irrigate 10mm", it explains *why* based on temperature and impending rain.
3. **Measurable environmental impact:** Tracks liters saved and corresponding energy/CO2 reductions from water pumping.
